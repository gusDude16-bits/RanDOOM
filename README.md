# 🕹️ RanDOOM

> A reimagined "2.5D" video game inspired by **DOOM**, built using Python and Pygame as a practical study project for Object-Oriented Programming (OOP).

---

## About the Project

**RanDOOM** was developed to apply core OOP principles — such as encapsulation, inheritance, polymorphism, and abstraction — in a real-world software development scenario. By recreating the classic arcade mechanics of DOOM, the project explores game loops, sprite management, collision detection, and modular architecture.

## Built With

* [Python](https://www.python.org/) — Programming language
* [Pygame](https://www.pygame.org/) — Library for writing video games
